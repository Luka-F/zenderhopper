# Zenderhopper

Online radio die om de paar minuten willekeurig wisselt tussen de zenders die jij aanvinkt.

**Openen:** https://luka-f.github.io/zenderhopper/

- Startlijst met Nederlandse zenders (NPO, 538, Qmusic, Sky Radio, Radio 10, Veronica en meer)
- Zelf instellen hoe lang een zender speelt (bijv. 3 tot 6 minuten) en of de zenders in elkaar overvloeien
- Zenders uit de hele wereld zoeken en toevoegen via de open database van [radio-browser.info](https://www.radio-browser.info/)
- Je lijst en instellingen blijven bewaard in je eigen browser; met *Lijst exporteren* maak je een reservekopie

Sneltoetsen: `spatie` afspelen/pauze, `N` volgende zender, `↑` `↓` volume.

Eén los HTML-bestand, zonder server of account. Je kunt `index.html` ook downloaden en lokaal openen; dan werken ook zenders die alleen een onbeveiligde http-stream hebben.
